# weather-cron

多源天气融合播报与灾害预警监控，100% 运行在 GitHub Actions。

- **数据源**：和风天气（播报主力）+ nmc 国家预警中心（官方预警校验）+ WAQI（空气质量）
- **推送**：企业微信群机器人 webhook
  （注：企微自建应用需配「企业可信IP」且禁第三方 IP，云端不可用，故走群机器人）
- **定时任务**：每日 06:00（北京时间）天气播报；每 30 分钟灾害预警监控

## 隐私设计

- 位置坐标 / adcode 一律存放于仓库 Secrets，源码不硬编码
- 云端开启静默模式（`WEATHER_QUIET=1`），日志不输出天气明细与位置
- 预警去重的状态文件只存哈希键，不含 adcode 或地名
